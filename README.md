# uif.eu design mockups — access-gated preview

Published viewer for the July 2026 feedback round.

**Live:** https://yukselono.github.io/uif-mockups-view/

The deck is encrypted (AES-256-GCM, PBKDF2-SHA256) and unlocked with an access
code in the browser — this repository contains ciphertext only, no readable
content. Source lives in the private `uif-new` repository; this repo holds the
generated build and is regenerated by `node build-viewer.js "<code>"`.
